# Yonela Jongola Portfolio

Professional one-page portfolio for Yonela Jongola, focused on AI cloud development, full-stack development, Azure, dashboards, APIs, and security-focused solutions.

## Structure

- `index.html` - main single-page portfolio
- `style.css` - responsive visual system
- `script.js` - mobile navigation and active section highlighting
- `image/CV.pdf` - downloadable CV

## Sections

- Home
- Work
- Certificates
- About
- Contact

## Run Locally

Open `index.html` in a browser, or serve this folder with any static file server.
